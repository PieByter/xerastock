# Instruksi pesan commit (untuk GitHub Copilot di VS Code)

File ini dirujuk oleh `.vscode/settings.json` lewat setting resmi
`github.copilot.chat.commitMessageGeneration.instructions`, sehingga tombol
generate commit di panel Source Control mengikuti konvensi repo ini.

## Format

Conventional Commits dengan ringkasan **Bahasa Indonesia**:

```
<tipe>(<scope>): <ringkasan imperatif>
```

- **Tipe**: `feat`, `fix`, `perf`, `refactor`, `test`, `style`, `docs`, `build`, `ci`, `chore`.
- **Scope** mengikuti workspace npm: `web`, `worker`, `engine`, `db`, `shared`.
  Untuk berkas root, dokumentasi, atau skrip: boleh tanpa scope.
- **Ringkasan**: kata kerja imperatif (`tambah`, `perbaiki`, `rapikan`, `perbarui`,
  `optimalkan`), maksimal 72 karakter total, tanpa titik di akhir.
- **Body**: daftar berkas dalam bentuk `- [baru|ubah|hapus] <path>`.

## Contoh subjek yang benar

```
feat(web): tambah halaman portfolio dan broker flow
fix(worker): perbaiki bar basi pada evaluasi sinyal
docs: perbarui panduan setup database
refactor(engine): rapikan perhitungan indikator
build: tambah dependensi dotenv
```

## Hindari

- Subjek generik: `update files`, `fix bug`, `WIP`, `changes`.
- Kalimat deskriptif panjang atau berakhir titik.
- Menyebut berkas rahasia (`.env` asli, `*.pem`, `*.key`) dalam pesan commit.
- Mengubah tipe/scope hasil pengelompokan `scripts/auto-commit.mjs` — script itu
  deterministik dan menjadi sumber kebenaran.
